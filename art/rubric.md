# 그림 검토 기준표

검토자는 **이 파일, `art/references/`의 기준 그림, 이번 회차 그림만** 봅니다.
이전 회차, 작업 대화, 지시서, 다른 검토자 점수는 보지 않습니다.

## 1. AI 티 (`ai_tell`, 1~10, 높을수록 AI 티가 덜 남)

| 점수 | 기준 |
|---|---|
| 9~10 | 사람이 의도해서 그린 것으로 보임. 형태·선·디테일이 일관됨 |
| 7~8 | 한두 군데 어색하지만 바로 AI라고 느껴지지 않음 |
| 5~6 | 눈여겨보면 AI 티가 보임 (아래 항목 2~3개) |
| 3~4 | 한눈에 AI 그림으로 보임 |
| 1~2 | 형태가 무너짐 |

확인할 것: 손가락·관절·대칭 오류, 의미 없는 장식, 녹아내린 경계, 부위마다 다른 광원, 지나친 광택·매끈함, 같은 무늬 반복, 글자 같은데 읽히지 않는 것.

## 2. 우리 그림체와 어울림 (`style_fit`, 1~10, 높을수록 잘 어울림)

| 점수 | 기준 |
|---|---|
| 9~10 | 기준 그림 옆에 두어도 같은 사람이 그린 것 같음 |
| 7~8 | 같은 게임으로 보이나 한두 요소(선 굵기·채도 등)가 다름 |
| 5~6 | 분위기는 비슷하나 그리는 방식이 눈에 띄게 다름 |
| 3~4 | 다른 게임 그림 같음 |
| 1~2 | 전혀 다름 |

확인할 것: 외곽선 굵기·색, 명암 단계 수, 채도·색 범위, 비율(머리:몸), 디테일 밀도, 테두리 처리(안티에일리어싱·픽셀).
