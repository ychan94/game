# KILNBORN 데모 출시 준비 (v0.1.0)

## 빌드 만들기
1. Godot 4.7.2 편집기 → 편집기 → **내보내기 템플릿 관리** → 내려받기 (한 번만)
2. `python3 scripts/export_demo.py windows` (웹은 `web`, 둘 다 `all`)
   - 결과: `build/windows/KILNBORN-demo.exe` (pck 를 exe 안에 넣음, 파일 하나)
   - 편집기에서 하려면: 프로젝트 → 내보내기 → "Windows" → 프로젝트 내보내기
3. 빌드에서 빠지는 것: tests · work · reports · perf · art · docs · scripts · src/core(보류한 AFTERSELF)
